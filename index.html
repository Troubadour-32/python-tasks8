🎬 Полное руководство: Flask-сайт с нуля

Мы соберём динамический многостраничный сайт «Киноподборщик»: пользователь отвечает на 6 вопросов, а сайт на основе его ответов подбирает жанр фильма и показывает 3 конкретных фильма.

📋 большой блок кликни — скопируется в буфер
🔒 маленький блок напечатай руками — так запомнишь
Логика такая: большие куски кода (целые файлы, длинные функции) — копируются кликом, чтобы ты не тратил час на набор. А короткие, но важные фрагменты (1–5 строк) — только руками, потому что именно они запоминаются через пальцы.

0 Введение: как вообще работает сайт

Что такое веб-приложение?
Это программа на сервере, которая принимает HTTP-запросы от браузера и возвращает HTTP-ответы.

0.1. Что происходит, когда ты открываешь сайт

  1. Вводишь адрес http://127.0.0.1:5000/test.
  2. Браузер отправляет HTTP-запрос методом GET.
  3. Flask ищет маршрут /test → вызывает функцию test().
  4. Функция читает из БД вопрос, собирает HTML, возвращает.
  5. Браузер рисует страницу.
Ты (браузер) делаешь заказ официанту (Flask). Официант идёт на кухню (БД), берёт блюдо, оформляет на тарелке (шаблон) и приносит тебе.

0.2. HTTP-методы: GET и POST

GET — «дай мне страницу». Данные в URL. Ничего не меняет.
POST — «прими данные». Данные в теле запроса. Меняет состояние.

0.3. Что такое Flask

Flask — микрофреймворк для Python. Даёт маршрутизацию, сессии, шаблоны, обработку ошибок. Всё остальное — подключается по желанию.

0.4. Декораторы

Декоратор — функция, оборачивающая другую функцию. @app.route('/test') над функцией означает: «зарегистрируй эту функцию как обработчик URL /test».

0.5. Сессии и cookie

HTTP не хранит состояние. Чтобы помнить — используют cookie и сессии. Сессия во Flask — это словарь, автоматически шифруемый в cookie. Хранит данные между запросами.
Для работы session обязателен SECRET_KEY.

0.6. SQLite и SQL

SQLite — встраиваемая БД, вся в одном файле movies.sqlite. Не нужен сервер. SQL — язык запросов: CREATE TABLE, INSERT, SELECT, DELETE.

0.7. Jinja2

Jinja2 — шаблонизатор во Flask. {{ выражение }} — вывести значение.
{% команда %} — цикл, условие, наследование.
{# комментарий #} — комментарий.

2 База данных — db_scripts.py

Схема БД: три таблицы.
  • quizzes — викторины (темы).
  • questions — вопросы.
  • answers — варианты ответов, у каждого — свой жанр.
Связь: один вопрос → много ответов.

2.1. Импорт и подключение

Модуль sqlite3 — стандартный в Python. conn — соединение. cursor — «рука» для запросов.

Напечатай эти две строки — это основа:

import sqlite3 db_name = 'movies.sqlite'

А весь блок функций для БД — можно скопировать кликом:

# ============================================================= # db_scripts.py — создание и наполнение базы данных # ============================================================= import sqlite3 db_name = 'movies.sqlite' conn = None cursor = None def open(): """Открывает соединение с БД.""" global conn, cursor conn = sqlite3.connect(db_name) cursor = conn.cursor() def close(): """Закрывает соединение с БД.""" cursor.close() conn.close() def do(query): """Выполняет SQL-запрос и сохраняет изменения.""" cursor.execute(query) conn.commit() def clear_db(): """Удаляет все таблицы, если они есть.""" open() do('DROP TABLE IF EXISTS answers') do('DROP TABLE IF EXISTS questions') do('DROP TABLE IF EXISTS quizzes') close() def create(): """Создаёт три таблицы: quizzes, questions, answers.""" open() do('PRAGMA foreign_keys = on') do('''CREATE TABLE IF NOT EXISTS quizzes ( id INTEGER PRIMARY KEY, name VARCHAR, description VARCHAR)''') do('''CREATE TABLE IF NOT EXISTS questions ( id INTEGER PRIMARY KEY, text VARCHAR)''') do('''CREATE TABLE IF NOT EXISTS answers ( id INTEGER PRIMARY KEY, question_id INTEGER, text VARCHAR, genre VARCHAR, FOREIGN KEY (question_id) REFERENCES questions (id))''') close() def add_quizzes(): """Добавляет три викторины.""" quizzes = [ ('Подбор фильма на вечер', 'Ответь на 5 вопросов — получи жанр'), ('Что посмотреть с друзьями?', 'Комедия, боевик или что-то другое?'), ('Романтический вечер', 'Подберём фильм для двоих'), ] open() cursor.executemany( 'INSERT INTO quizzes (name, description) VALUES (?, ?)', quizzes) conn.commit() close() def add_questions(): """Добавляет 6 вопросов.""" questions = [ ('Какое у тебя сейчас настроение?',), ('С кем будешь смотреть?',), ('Сколько у тебя времени?',), ('Что важнее — сюжет или картинка?',), варианты ответов с указанием жанра.""" answers = [ (1, 'Хочу приключений', 'adventure'), (1, 'Хочу подумать', 'drama'), (1, 'Хочу расслабиться', 'comedy'), (1, 'Хочу пощекотать нервы', 'thriller'), (2, 'Один', 'drama'), (2, 'С друзьями', 'comedy'), (2, 'С девушкой/парнем', 'romance'), (2, 'С семьёй', 'family'), (3, 'Меньше часа', 'short'), (3, '1–2 часа', 'standard'), (3, 'Хоть всю ночь', 'epic'), (4, 'Сюжет', 'drama'), (4, 'Картинка', 'action'), (5, 'Да', 'comedy'), (5, 'Нет', 'thriller'), (6, 'Да', 'drama'), (6, 'Нет', 'action'), ] open() cursor.executemany( 'INSERT INTO answers questions.text, answers.text, answers.genre FROM questions, answers WHERE answers.question_id = questions.id AND questions.id = ? ORDER BY answers.id ''' cursor.execute(query, [question_id]) result = cursor.fetchall() close() return result def first_question(): """Возвращает id первого вопроса.""" open() cursor.execute('SELECT MIN(id) FROM questions') result = cursor.fetchone() close() return result[0] if result else None def total_questions(): """Возвращает количество вопросов.""" open() cursor.execute('SELECT COUNT(*) FROM questions') result = cursor.fetchone() close() return result[0] if result else 0 def show(table): """Печатает содержимое таблицы (для отладки).""" open() cursor.execute('SELECT * FROM ' + table) print(cursor.fetchall()) close() def show_tables(): show('questions') show('answers') show('quizzes') def main(): clear_db() create() add_quizzes() add_questions() add_answers() show_tables() print('\n=== База данных создана ===') print('Всего вопросов:', total_questions()) print('Вопрос 1:', question_after(1)) if __name__ == '__main__': main()
Почему ('текст',) — кортеж, а ('текст') — просто строка?
(Ответ: кортеж из одного элемента требует запятую. Без неё Python считает это выражением в скобках.)

3.2. Ключевые приёмы — напечатай сам

Приём 1. Прибавить очко жанру:

scores[genre] = scores.get(genre, 0) + 1
.get(genre, 0) — если жанра ещё нет в словаре, вернёт 0. Иначе — текущее число. Затем +1.

Приём 2. Найти победителя:

winner = max(scores, key=scores.get)
max с key находит ключ словаря с максимальным значением.

Приём 3. Redirect после POST:

return redirect(url_for('result'))
Паттерн Post/Redirect/Get: чтобы F5 не отправлял форму заново.

6 Запуск и отладка

  1. pip install flask — один раз.
  2. python db_scripts.py — один раз.
  3. python app.py — каждый раз для запуска.
  4. Открыть http://127.0.0.1:5000.
⚠ Симптом → причина:
  • «no such table» — не запущен db_scripts.py.
  • «TemplateNotFound» — файл не в templates/.
  • Session не работает — нет SECRET_KEY.
  • Форма не отправляется — нет method="POST".
  • Результат не тот — у кнопки value="{{ opt.genre }}"?
